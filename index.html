☁️ Google Sheets Auto-Sync Every record auto-saves to your Google Sheet
📋 Setup Steps:
1. Open Google Sheets → New Sheet → Name it "Car Records"
2. Go to Extensions → Apps Script
3. Paste the code from google-apps-script.js file (in this folder)
4. Click Deploy → New Deployment → Web App
5. Set "Who has access" → Anyone → Deploy → Copy the URL
6. Paste the Web App URL below and click Save

✅ Once URL is saved, every new entry automatically syncs to Google Sheets. The ☁️ icon in the table shows sync status per record.
